# Project Governance & Rules

All development, maintenance, and interaction in this repository must adhere to the Standard Operating Procedures established in [.master/SOP.md](file:///.master/SOP.md) and [.agents/rules/sop_protocol.md](file:///.agents/rules/sop_protocol.md).

## Mandatory Protocols

1. **TL;DR at Top**: Every response begins with a concise `## TL;DR`.
2. **Master Logs Maintenance**: Update `.master/MasterChangeLog.md`, `.master/TroubleshootingLog.md` (with usage counts), `.master/IdeasLog.md`, and `.master/FileManifest.md`.
3. **End-of-Response Report Card**: Include self-grade, checklist, context window health, hallucination check, and 3 improvement ideas.
