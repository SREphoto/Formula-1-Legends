# Workspace Rule: Standard Operating Procedures (SOP) Protocol

Every response in this workspace must strictly follow the SOP rules:

1. **TL;DR at the Top**: Every response must start with a `## TL;DR` summarizing changes and current status.
2. **Master Logs Maintenance**:
   - Update `.master/MasterChangeLog.md` on any code changes.
   - Update `.master/TroubleshootingLog.md` on any bug fixes. Increment usage counters if a known fix was applied and keep sorted by usefulness.
   - Update `.master/IdeasLog.md` with new feature and expansion ideas.
   - Update `.master/FileManifest.md` on file additions, deletions, renames, or archiving.
   - Store archive documents in `.master/archive/`.
3. **End-of-Response Report Card**:
   Every response milestone must conclude with the standardized `## Report Card` containing:
   - Task Completion % (1–100) & itemized checklist.
   - Quality of Work % (1–100).
   - Problem & root cause synopsis.
   - Context window health report & recommendation on new conversation.
   - Master log & manifest update checkoff.
   - Hallucination self-check.
   - 3 Improvement ideas (gameplay, graphics, UI/UX, SEO, security, profitability, etc.).
